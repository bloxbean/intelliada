Reports fixed-width numbers inside a class annotated @StateContract, mirroring JOUST's processor lint (SubsetLint):
  • the types int, long, short, char, float and double where they are written (byte is allowed, since byte[] is a bytestring);
  • their boxes (Integer, Long, Short, Byte, Character, Float, Double);
  • narrowing calls such as intValue(), longValueExact() or doubleValue();
  • arithmetic (binary, unary or compound) whose type is fixed-width, byte included;
  • variables, including var and lambda parameters, whose inferred type is fixed-width.

JuLC compiles this arithmetic as unbounded integers and intValue() as the identity, while the JVM wraps at 32 or 64 bits, so the two runs of the same method could disagree. Compute in BigInteger.

Advice only: JOUST's build stays the authority (IntelliAda ADR-004 D10).
