Reports MerkleMap.reads(), writes() and root(), and constructing a MerkleMap or a MapEntry, inside a class annotated @StateContract.

A MerkleMap is only a top-level state component. Its internals differ between the JVM run and the on-chain run, and a hand-made map carries reads nobody proved. Use MerkleMaps.empty() and the MerkleMaps helpers. JOUST's processor rejects these.

Advice only: JOUST's build stays the authority (IntelliAda ADR-004 D10).
