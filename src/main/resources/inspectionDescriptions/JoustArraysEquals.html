Reports Arrays.equals(byte[], byte[]) inside a class annotated @StateContract.

On the JVM it compares contents, but the JuLC version JOUST pins (0.1.0-pre21-rc1) does not compile it: "Unknown method: java.util.Arrays.equals" (JULC0024; written java.util.Arrays.equals, JULC0123). Use ByteStringLib.equals(a, b); the quick fix rewrites the call.

Advice only: JOUST's build stays the authority (IntelliAda ADR-004 D10).
